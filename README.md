# 🏫 Sistema Gerenciador de Reservas (Salas & Laboratórios)

Sistema web desenvolvido para automatizar e organizar o agendamento de espaços acadêmicos e laboratórios, evitando conflitos de horários e garantindo o controle de acesso por perfil de usuário.

> **Nota:** Este projeto foi desenvolvido exclusivamente para fins educacionais e utiliza dados fictícios.

---

## 🚀 Tecnologias Utilizadas

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS), Bootstrap 5
- **Backend:** PHP (MySQLi)
- **Banco de Dados:** MySQL
- **Gerenciador de Banco de Dados:** phpMyAdmin / Laragon 

---

## ✨ Principais Funcionalidades

- **Controle de Acesso (RBAC):** Autenticação com permissões distintas para Administradores e Professores.
- **Validação Anti-Conflito:** Algoritmo no backend que impede agendamentos simultâneos para a mesma sala/laboratório.
- **Navegação Dinâmica:** Alternância entre a lista de agendamentos e o formulário sem recarregamento de página.
- **Interface Responsiva:** Design limpo e moderno em *Light Mode* no padrão *squared-edge* (Bootstrap 5).

---

## 🛠️ Como Executar o Projeto Localmente

1. baixe os arquivos do projeto

2. tenha um server como laragon ou xampp ligado e com o PHPmyadmin baixado e online

3. baise o arquivo sql ontem todos os dados do banco, 

4. execute os outros arquivos em alguma area de desenvolvimento da sua preferencia

5. execute o projeto em sua area de desenvolvimento e faça suas alteraçoes, 
( se for usar localmente, sem uso de internet, mude o sistema para uso de localHost pelo javaScript )

6. faça bom aproveito
